# Lab 001: Enterprise AI System Inventory

Status: Planned

## Scenario
A fictional financial services firm lacks centralized visibility into its AI systems.

## Objective
Build a Streamlit registration form and SQLite-backed inventory with ownership, intended use, data classification, risk tier and approval status.

## Acceptance criteria
- [ ] Define and validate the system schema.
- [ ] Create the SQLite database.
- [ ] Register and display five synthetic AI systems.
- [ ] Reject missing required fields and duplicate identifiers.
- [ ] Flag unapproved high-risk systems and missing ownership.
- [ ] Test persistence and validation.
- [ ] Capture sanitized evidence and document limitations.

## Framework mapping
Review NIST AI RMF GOVERN 1.6, GOVERN 2.1 and relevant MAP outcomes. Validate the mapping during implementation.

## Deliverables
Source code, schema, test results, architecture and portfolio case study. No production authorization or compliance claim is implied.
