# ai-governance-labs

A hands-on AI governance engineering portfolio exploring how enterprise AI oversight can be implemented, tested and automated.

## Scenario
A fictional financial services organization is adopting AI. All lab data must be synthetic; never commit employer information, credentials or personal data.

## Getting started
```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m streamlit run app.py
```
